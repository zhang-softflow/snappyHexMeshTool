# Changelog

## 1.0.0 — 2026-11-25
- First release.
- `foamSHM` CLI: `build`, `tree`, `search`, `show`, `example`, `template` (`--write`), `check` (`--dict-only`), `html`.
- Keyword database from the annotated snappyHexMeshDict (including commented-out optional entries), meshQualityDict, the C++ dictionary reads (mandatory/optional, defaults), Enum name tables, searchableSurface types and the tutorial dictionaries.
- Per-version databases in `~/.local/share/foamSHM`, bundled database for OpenFOAM-v2606.
- Offline `catalog.html` with tree view, search, copyable snippets and a template.
- Claude Code skill `openfoam-snappyhexmesh` and `install.sh`.
